# Notice

Hinweis-Box für Dinge, die jemand erledigen oder wissen muss, ohne dass etwas blockiert.

- Grund `notice-bg`, Rahmen `notice-border`, Text `notice-ink`.
- Titel nennt die Anzahl («2 Hinweise»), Liste mit konkreten Handlungen und Fristen.
- Für echte Fehler `StatusPill critical` am betroffenen Objekt statt Notice.
