# Card

Weisse Fläche mit Rahmen, die einen Inhaltsblock eines Screens zusammenfasst.

- Hintergrund `surface`, Rahmen `border`, Radius `radius-lg`, Innenabstand `space-6`. Keine Schatten.
- `title` als `section-title`; `meta` rechts für Bezugsgrössen wie «pro 10 Portionen».
- `tone="panel"`: dunkles Panel (`panel`) für die eine Zusammenfassung pro Screen (Live-Vorschau, Disposition). Nie mehrere Panels nebeneinander.
- Karten stehen in Flex- oder Grid-Reihen mit `gap` `space-6` und brechen auf schmalen Screens um.
