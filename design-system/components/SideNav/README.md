# SideNav

Hauptnavigation links; auf schmalen Screens bricht sie über den Inhalt um.

- Breite `sidenav-width`, Grund `surface`, Trennlinie `border`.
- Aktiver Eintrag `accent-tint` / `accent-strong` mit `aria-current="page"`.
- Noch nicht gebaute Bereiche als `disabled` (`ink-disabled`), nicht klickbar.
- Reihenfolge: Leitstand, Anlässe, Ressourcen, Speisen & Rezepte, Produktionsplan, Einkauf, Stammdaten.
