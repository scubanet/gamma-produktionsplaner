# Fieldset

Gruppe zusammengehöriger Checkboxen mit Legende, z.B. Produktionssysteme oder Regenerationsarten einer Komponente.

- Legende im Stil von `label` (`ink-muted`), Inhalt im 2-spaltigen Grid, auf schmalen Screens einspaltig.
- `hint` unter der Gruppe für Annahmen oder Erklärungen, z.B. Haltbarkeiten der Systeme.
- Natives `<fieldset>`/`<legend>`: Screenreader lesen die Legende zu jeder Checkbox.
