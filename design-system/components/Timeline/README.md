# Timeline

Zeitplan (Gantt) für Produktion und Tagesablauf, eine Zeile pro Station oder Anlass.

- Zeit in Stunden als Zahl (`19.5` = 19:30); Werte über 24 laufen in den nächsten Tag (`25` = 01:00).
- Balkenfarbe nach Ort (`location`), siehe LocationTag. Beschriftung im Balken, voller Text im Tooltip.
- `marker` setzt eine gestrichelte Linie in `accent` für den einen Zeitpunkt, der zählt (z.B. Essen 19:30).
- Raster alle 2 Stunden; Achse in `figure`-Mono.
