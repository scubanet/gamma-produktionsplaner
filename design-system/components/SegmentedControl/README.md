# SegmentedControl

Wahl aus 2–4 sich ausschliessenden Optionen, z.B. Serviceart oder Tag −1 / Tag 0.

- Grund `surface-sunken`, aktives Segment `surface` mit `shadow-raised` und Schrift 600 – der einzige Schatten im System.
- Als `radiogroup` mit `aria-checked`; Beschriftung über `label` (für Screenreader).
- Mehr als 4 Optionen: Auswahlliste statt Segmented Control.
