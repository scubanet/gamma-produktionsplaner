# Chip

Kleines Merkmal an einem Arbeitsschritt: Gerät, Temperatur, Zeit, HACCP.

- `neutral` (Gerät): `surface-sunken` / `ink-secondary`.
- `temp`: Temperatur, `loc-zentral-tint` / `loc-zentral-ink`.
- `aktiv`: aktive Arbeitszeit, `accent-tint` / `accent-strong`.
- `unbeaufsichtigt`: Zeit, die nur das Gerät bindet, kursiv in `ink-muted` auf `grid-line`.
- `haccp`: Kontrollpunkt, `status-warn-bg` / `status-warn-ink`.
- Für Status eines Objekts StatusPill verwenden, nicht Chip.
