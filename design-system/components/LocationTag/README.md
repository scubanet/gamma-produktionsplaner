# LocationTag

Legende und Kennzeichnung des Arbeitsorts eines Prozessschritts.

- `zentral` = Zentralküche (`loc-zentral`, Blau), `vorort` = beim Kunden (`loc-vorort`, Orange), `logistik` = Transport (`loc-logistik`, Grau).
- Dieselben Farben färben Zeitplan-Balken und Schrittnummern. Blau und Orange unterscheiden sich auch in der Helligkeit.
- Pro Ansicht nur eine Farbcodierung: im Leitstand stehen dieselben Farben für Anlass A/B/C – dann keine Ort-Farben im selben View.
